# Historical build and QA records

This directory preserves **38 original release notes and audit files** from earlier portfolio iterations (V8–V20 and early submission drafts).

> **Historical context only:** File names such as “final”, “release”, “verified” or “deployed” refer to their original development checkpoints. Their claims about branch status, test counts, model performance, accessibility or external deployments are **not** statements about today's website. Some old references use the repository's former root paths; consult current source and [the changelog](../../CHANGELOG.md) instead.
